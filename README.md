# VBA-TVM
A VBA UserForm tool for solving time value of money (TVM) problems with two unknowns, similar to those seen in Exam FM.

An example question would look like:

> [!NOTE]
> Annuity A pays $X$ at the end of each year for 10 years. Its Present Value is $5,000$.
> 
> Annuity B pays $2X$ at the end of each year for 20 years. Its Present Value is $12,000$.
>
> Given they are evaluated at the same $i$, find $X$.
